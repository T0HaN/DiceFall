# DiceFall - Помощник Мастера Подземелий D&D 5e

Веб-приложение для создания и управления персонажами Dungeons & Dragons 5-й редакции с возможностью совместной игры.

## Возможности

### Лист персонажа
- **Основная информация**: имя, класс, уровень, раса, мировоззрение, опыт, предыстория, языки
- **Характеристики**: Сила, Ловкость, Телосложение, Интеллект, Мудрость, Харизма с автоматическим расчетом модификаторов
- **Спасброски**: с учетом владения и бонуса мастерства
- **Навыки**: все 18 навыков D&D 5e с автоматическим расчетом бонусов
- **Пассивная внимательность**: автоматический расчет
- **Очки здоровья**: максимум, текущие, временные HP
- **Кости хитов**: тип, количество, использованные
- **Боевые характеристики**: КД (AC), инициатива, скорость
- **Оружие и броня**: управление арсеналом персонажа
- **Классовые и расовые особенности**
- **Черты (Feats)**
- **Инвентарь и снаряжение**
- **Деньги**: золото, серебро, медь, платина, электрум
- **Заклинания**: ячейки заклинаний, Сл спасброска, бонус атаки

### Автоматические расчеты
- **Уровень по опыту**: автоматическое определение уровня на основе таблицы XP D&D 5e
- **Модификаторы характеристик**: формула (значение - 10) / 2
- **Бонус мастерства**: автоматически рассчитывается от уровня
- **Бонусы спасбросков и навыков**: с учетом владения
- **Сл спасброска заклинаний**: 8 + бонус мастерства + модификатор
- **Бонус атаки заклинанием**: бонус мастерства + модификатор

### Совместная игра
- **Создание комнаты**: Мастер создает комнату с уникальным кодом
- **Присоединение игроков**: игроки подключаются по коду или пригласительной ссылке
- **WebSocket связь**: реальное время обновление данных
- **Разделение прав**:
  - Мастер может просматривать все листы персонажей и добавлять опыт
  - Игроки редактируют только свои листы
  - Мастер не может редактировать листы игроков (только добавлять опыт)

### Броски кубов
- **Быстрые броски**: d4, d6, d8, d10, d12, d20, d100
- **Пользовательские броски**: поддержка формата типа "2d6+3", "3d8"
- **Проверки характеристик**: с учетом модификаторов и владения
- **Проверки навыков**: быстрый бросок для любого навыка
- **История бросков**: отображение всех бросков с именами игроков
- **Критические успехи/неудачи**: визуальное выделение

### Управление персонажем
- **Сохранение**: сохранение персонажа на сервере
- **Загрузка**: загрузка сохраненного персонажа по ID
- **Экспорт**: скачивание персонажа в формате JSON
- **Импорт**: загрузка персонажа из JSON-файла

## Запуск приложения

```bash
# Установка зависимостей (если нужно)
pip install flask flask-socketio python-engineio python-socketio eventlet

# Запуск сервера
python app.py
```

Сервер запустится на `http://localhost:5000`

## Использование

### Для Мастера:
1. Откройте `http://localhost:5000`
2. Введите ваше имя в поле "Создать комнату (Мастер)"
3. Нажмите "Создать комнату"
4. Скопируйте код комнаты или ссылку и отправьте игрокам

### Для Игроков:
1. Откройте полученную ссылку или `http://localhost:5000`
2. Введите ваше имя и код комнаты
3. Нажмите "Присоединиться"
4. Создайте лист персонажа

### Добавление опыта (Мастер):
1. Перейдите на вкладку "👑 Мастер"
2. Выберите персонажа из списка
3. Введите количество опыта
4. Нажмите "Добавить опыт"
5. Уровень персонажа автоматически пересчитается

### Броски кубов:
1. Перейдите на вкладку "🎲 Броски"
2. Нажмите на нужный тип куба или введите пользовательское выражение
3. Результат увидят все участники комнаты

## Технологии

- **Backend**: Python, Flask, Flask-SocketIO
- **Frontend**: HTML5, CSS3, JavaScript
- **Real-time**: WebSocket (Socket.IO)
- **Хранение**: память сервера (для продакшена рекомендуется база данных)

## Примечания

- Данные хранятся в памяти сервера и будут потеряны при перезапуске
- Для постоянного хранения рекомендуется подключить базу данных (PostgreSQL, MongoDB и т.д.)
- В продакшене необходимо изменить секретный ключ и настроить безопасность
